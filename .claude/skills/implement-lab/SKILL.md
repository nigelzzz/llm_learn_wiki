---
description: Build a minimal coding lab for a technical concept, including implementation, tests, and notes.
---

Create or update a minimal lab for the requested topic.

Steps:

1. Create a folder under `domains/<domain>/labs/<topic>/`
2. Write a short README explaining the goal.
3. Implement the smallest working version.
4. Add tests or a runnable demo.
5. Run the tests or demo.
6. Explain the result.
7. Add common bugs to the README.
8. Update the domain confusion log.

Constraints:

- Keep the implementation small.
- Prefer Python for math demos.
- Prefer C++ for LeetCode-style algorithms.
- Prefer CUDA only when explicitly requested.
- Do not over-engineer.
