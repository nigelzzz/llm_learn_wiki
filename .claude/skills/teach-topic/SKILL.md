---

Teach the topic using this format:

## 1. Big Picture
Explain what this topic is and why it exists.

## 2. First-Principles Explanation
Explain from the simplest version.

## 3. Core Formula / Algorithm / Invariant
Show the key math, algorithm, or invariant.

## 4. Minimal Example
Use a tiny concrete example.

## 5. Implementation View
Show pseudo-code or minimal code.

## 6. Common Traps
List common mistakes and wrong intuitions.

## 7. Interview Angle
Explain how to say this in an interview.

## 8. Checkpoint Quiz
Ask me 5 questions.

## 9. Mini Assignment
Give me one small exercise.

Use Traditional Chinese.
